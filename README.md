# EPS Research Lab — Team 1

Repository for the year-long research paper produced by the EPS Research Lab,
in collaboration with Analysis Group.

## Folder structure

| Folder | What goes in it |
|---|---|
| `input/` | Raw data. **Never edited by hand.** Whatever we download or receive goes here untouched. |
| `scripts/` | All R code. Numbered in the order it should run (`01-clean.R`, `02-estimate.R`). |
| `output/` | Tables, figures, rendered documents. Generated by code, so **not tracked in Git**. |
| `members/` | One short file per analyst. Used in the setup session. |
| `analysis.qmd` | Our main Quarto document. |

## Working rules

1. **Pull before you start. Push before you stop.** Every time, without exception.
2. **Small, frequent commits.** A message says *why*, not *what*.
3. **Never edit anything in `input/`.** Clean data with a script that writes a new file.
4. **No large data in Git.** Over ~50MB does not belong here; GitHub rejects 100MB outright.
5. **One person per file where possible.** Simultaneous edits to one file create conflicts.
6. **If a push is rejected**, pull first, then push again. If it looks messy, ask in the group chat.

## Getting set up

**File → New Project → Version Control → Git**, paste the HTTPS URL, choose a folder,
Create Project. Always open the project through its `.Rproj` file — that is what makes
`here::here()` resolve paths correctly. You should never need `setwd()`.
